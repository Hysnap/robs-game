# RobsGame

RobsGame is a Godot 4.7, data-driven, turn-based economic and society
simulation.

## Documentation

The [RobsGame Wiki]([https://github.com/Hysnap/robs-game/wiki]) is the single source of truth for
architecture, development workflow, data authoring, runtime systems, UI
contracts, and verification commands.

Start with:

1. [Wiki Home]([https://github.com/Hysnap/robs-game/wiki])
2. [Development workflow]([https://github.com/Hysnap/robs-game/wiki/Development-Workflow])
3. [Data authoring]([https://github.com/Hysnap/robs-game/wiki/Standardised-Modular-Verb-System-Specification])

Documentation changes belong in `robs-game.wiki/`. Do not add replacement
README or HOWTO guides inside runtime directories.
